自从上次我的小米路由器mini刷Tomato Phoenix之后，稳定用了好几天，但是2.4Ghz wifi下始终跑不满我的50M小水管，而且功能也没那么全面，于是又开始了折腾，先打算刷会小米官方固件，但是在breed恢复台里刷了两边都失败了，就不打算刷回去了，官方的也没有什么卵用，于是就开始了寻找其他固件，想起以前刷的华硕固件，在[什么值得买][1]的这篇文章里，跟着教程刷完之后是这个样子的。

不仅在2.4Ghz下wifi可以满速，还有ss功能，这样就不用手机电脑开着小飞机了，还可以美化管理页面美滋滋，背景字体logo都可以该，自己喜欢什么样就可以变成什么样，还有我在路由器里搭建个小网站的想法也实现了，不过就打开的个探针，系统负载就已经6了，感觉网络都不怎么好使了，所以试试就可以了，路由器么还是老实的上网用吧，网站插件也许多，可以锐捷登录意味着可以用在校园里了，还是去除广告的功能，ftp，samba就不谈了，反正这是我想要的路由器的样子。
