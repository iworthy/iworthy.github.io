KMS一键激活Windows所有版本、office所有版本、一句命令激活WINDOWS


<!--more-->

在管理员权限的 cmd 或者 powershell 中执行
##激活 Windows##

    slmgr /skms int.worthy.cc
    slmgr /ato

##更换密钥##

    wmic os get caption
    slmgr /ipk xxxxx-xxxxx-xxxxx-xxxxx

##激活 Office##

    cd "C:\Program Files\Microsoft Office\Office16" #64位office
    cd "C:\Program Files (x86)\Microsoft Office\Office16" #32位office
    cscript ospp.vbs /sethst:int.worthy.cc
    cscript ospp.vbs /act
