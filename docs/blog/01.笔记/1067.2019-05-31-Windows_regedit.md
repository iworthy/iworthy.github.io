Windows系统的许多设置都可以通过修改注册表来完成，记录Windows注册表的一些使用方法。
## 如何打开注册表编辑器

方法一：运行“regedit”命令打开注册表编辑器
Win + R 快捷键调出“运行”对话框，输入“regedit”。

方法二：通过“任务管理器”运行新任务
选择“任务管理器”，显示“任务管理器”详细信息，点击“文件 - 运行新任务”弹出“新建任务”对话框。
输入 regedit ，确定，即可打开注册表编辑器。

## 注册表导出/导入方法
### 备份整个注册表
打开注册表编辑器，在左侧列表中选中根部的“计算机”，然后点击“文件”菜单，选择“导出”。

### 备份注册表中的某一项
在注册表编辑器中选中需要备份的项，在该项上点击右键，选择“导出”。

### 恢复注册表的方法

方法一：
打开注册表编辑器，点击“文件”菜单，选择“导入”，然后在“导入注册表”窗口中选择之前备份的reg文件。
方法二：
无需打开注册表编辑器，直接双击之前备份的reg文件即可。

### 快速定位到注册表编辑器某一项
方法一：
注册表编辑器中增加了地址栏，把路径复制到地址中，回车即可快速定位。
方法二：
使用VBS脚本自动注入定位

    Dim objHTA
    Dim cClipBoard
    Dim WshShell
    set objHTA=createobject("htmlfile")
    cClipBoard=objHTA.parentwindow.clipboarddata.getdata("text")
    Set WshShell = WScript.CreateObject("WScript.Shell")
    WshShell.RegWrite "HKCU\Software\Microsoft\Windows\CurrentVersion\Applets\Regedit\LastKey", cClipBoard, "REG_SZ"
    WshShell.Run "regedit.exe -m"
    Set objHTA = nothing
    Set WshShell = nothing
方法三：
使用微软RegJump快速跳转到注册表项

## 同时打开多个注册表编辑器

    regedit -m 或 regedit /m
