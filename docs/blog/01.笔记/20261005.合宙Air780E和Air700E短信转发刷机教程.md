这篇教程面向将合宙 Air780E／Air700E 开发板用作短信转发器的场景。基本流程是准备 Luatools 与项目文件，配置通知渠道，然后烧录固件和脚本。定位、联网、语音等其他用途不在原文教程范围内。

<!--more-->

## 准备文件

1. 下载合宙的 [Luatools 烧录工具](https://luatos.com/luatools/download/last)，初次使用可参考[官方安装与使用说明](https://doc.openluat.com/wiki/37?wiki_page_id=4489)。
2. 从 [air780e-forwarder 项目仓库](https://github.com/lageev/air780e-forwarder)获取项目文件。仓库中的 `core` 目录存放固件，`script` 目录存放 Lua 脚本。
3. 如需单独下载 EC618 固件，可查看[合宙 LuatOS 发布页](https://gitee.com/openLuat/LuatOS/releases)，按所用模组和所需功能选择。原文列出的 V1105 是 2023 年的版本示例，不应直接视为当前最新版。

固件文件名通常标示功能和版本，例如基础版、带 TTS 的版本或带 RNDIS 网卡功能的版本。原文建议一般用途选择 `FULL` 版本；具体仍需与开发板型号及项目脚本要求核对。首次烧录时，脚本文件应按项目需要一并选入。

## 配置通知渠道

烧录前打开项目的 `script/config.lua`，按自己使用的推送服务填写通知方式和相应的密钥或 Webhook 地址。`NOTIFY_TYPE` 可指定多个渠道，例如同时使用 Bark 和钉钉：

```lua
NOTIFY_TYPE = {"bark", "dingtalk"}
```

只使用一个渠道时，按当前项目文件中的注释填写即可。以 Bark 为例，从自己的 Bark 应用取得推送地址，将其中的个人 Key 填入配置文件的 `BARK_KEY`；若没有自建 Bark 服务，原文提示无需改动 API 地址。其他渠道的配置方式可查看 `config.lua` 中的注释和对应文档。

保存配置后再烧录。真实 Token、Webhook 和 Bark Key 应只保存在自己的设备或私有配置中，别把它们写进公开分享的文章或代码仓库。

## 烧录固件和脚本

1. 用 USB-C 数据线将开发板连接电脑，先不要给开发板开机。
2. 在 Luatools 中勾选“4G 模块 USB 打印”，打开右上方的项目管理，创建一个新项目。
3. 在项目中选取对应的固件文件，以及需要烧录的 Lua 脚本文件。
4. 点击“下载底层和脚本”，观察工具中的准备、下载及完成提示。开发板进入下载模式的具体按键动作，请对照[原文截图和演示](https://www.kdocs.cn/l/coe1ozIlSX70)及手头板卡的说明操作。
5. 烧录完成后开机，插入有短信功能的 SIM 卡，用 5 V USB 电源供电。需要排查运行情况时，可连接电脑，在 Luatools 中查看日志。

原文指出，两款板卡从左到右分别是电源键、重置键和 BOOT 键。以后若只是更换脚本，可在 Luatools 中新建项目并选择“下载脚本”，无需每次重刷底层固件。

## 兼容性与排查

短信转发是否可用，取决于**具体模组子型号、固件、运营商和 SIM 卡的短信能力**。项目仓库目前说明：Air700E 的支持范围因子型号而异，部分型号仅支持移动卡；电信短信还涉及模组、固件和 VoLTE 支持。开始排查前，先用普通手机卡确认 SIM 本身可以收发短信，再核对[项目兼容性说明](https://github.com/lageev/air780e-forwarder#%E8%BF%90%E8%90%A5%E5%95%86%E5%92%8C%E5%9B%BA%E4%BB%B6%E5%85%BC%E5%AE%B9%E6%80%A7)。
