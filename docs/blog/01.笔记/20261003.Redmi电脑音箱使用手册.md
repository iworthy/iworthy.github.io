Redmi 电脑音箱支持 USB、蓝牙和 AUX IN 三种音频输入。接入电脑 USB 接口后，可直接作为电脑扬声器使用。本文将原手册中的按键、指示灯和常见故障处理方法整理成便于查找的文字版本；产品外观与接口位置请对照[原页示意图](https://cdn.cnbj1.fds.api.mi-img.com/ics-resources/articles/6638aa19c75580331050b967.html)。

## 接口与声音模式

音箱顶部有切换键、灯光键和麦克风，侧面是可旋转的多功能键，背部为数据线与 AUX IN 接口。连接电脑时，将音箱数据线插入电脑 USB 接口，电脑端选择“Redmi电脑音箱”作为输出设备。音箱也能通过蓝牙或 3.5 mm 音频线播放，但仍需要 USB 供电。

原手册介绍的声学结构为左右各一组 44 × 80 mm 跑道形全频单元与无源辐射器，单个扬声器额定功率 5 W、峰值功率 7 W；音箱采用 53° 上扬角度。手册还列出五种 DSP 音效、五种 RGB 灯效，以及 USB → 蓝牙 → AUX IN 的循环切换顺序。

## 按键速查

| 按键 | 短按 | 连续短按 | 长按或旋转 |
| --- | --- | --- | --- |
| 多功能键 | 开机；播放／暂停；接听／挂断电话 | 两次切下一曲；三次切上一曲 | 长按 2 秒关机或拒接电话；长按 8 秒恢复出厂设置；顺时针旋转调高音量，逆时针旋转调低音量 |
| 切换键 | 切换音效 | 两次切换音频通道 | 长按 2 秒进入蓝牙配对模式 |
| 灯光键 | 切换 RGB 灯效 | — | 长按 2 秒开启或关闭 RGB 灯效 |

## 指示灯与待机

| 灯光 | 状态 |
| --- | --- |
| LED 白色常亮 | 蓝牙已连接 |
| LED 白色闪烁 | 蓝牙配对中 |
| LED 橙色闪烁 | 充电中 |
| LED 红色常亮 | 设备故障 |
| RGB 白色呼吸 | 来电通话中 |
| RGB 白色闪烁 | 来电呼入 |
| RGB 橙色呼吸 | 休眠 |

停止播放和操作约 30 分钟后，音箱会进入休眠，RGB 灯带显示橙色呼吸效果；再过约 30 分钟无活动，则进入灯带熄灭的待机状态。播放相应通道的音频或操作任意按键可唤醒。音量信号过小时也可能提前表现为休眠，先按任意键试试。

## 常见问题

### 无法开机或没有声音

先检查数据线是否插牢，接通 USB 后短按多功能键开机。若已开机却没有声音，核对音箱所选通道与播放设备是否一致：电脑 USB 播放时应选择 USB 通道，并在电脑中选“Redmi电脑音箱”；蓝牙播放时检查配对；AUX IN 播放时检查音频线、音源和设备静音状态。

### 音量调节不生效或麦克风声音小

音箱旋钮调节无效时，先确认电脑系统音量没有设得过低或静音。麦克风音量过小时，在 Windows 的“系统 → 声音 → 输入设备”或 macOS 的“系统设置 → 声音 → 输入”中选择“麦克风（Redmi电脑音箱）”，检查输入音量。原手册还提供了固件升级方案，见文末链接。

### 有杂音

- **USB 通道**：检查电脑或其他播放设备的音源本身。
- **蓝牙通道**：检查音源与周围无线干扰。
- **AUX IN 通道**：若音频线和供电 USB 同时连接同一台电脑，可尝试改用独立 USB 电源适配器供电。连接电脑时，原手册更推荐直接走 USB 音频通道。

### 音量突然降低

长时间高音量播放约 6～8 小时后，音箱可能进入低功率模式，播放功率和灯带亮度降低，LED 约每 5 秒橙色双闪一次。另一个可能原因是扩展坞或 USB 集线器供电不足；可将数据线直接接到电脑 USB 接口或 USB 电源适配器。

手册称音箱内置一节 1500 mAh 的 18650 锂电池，用于补足播放时的供电，**不能作为断电后的独立播放电池**。进入低电状态后，边播放边充至正常电量约需 6 小时；停止播放并保持供电约需 2 小时。这些时间是手册给出的参考值。

### 蓝牙配对失败、搜不到或频繁断开

长按顶部切换键 2 秒，使音箱重新进入蓝牙配对模式；在手机或电脑上删除旧的“Redmi电脑音箱”配对记录，再重新搜索连接。若播放时频繁断开，先检查 USB 供电连接，必要时改用 USB 电源适配器供电后重新配对。
