> 一直想学python，今天把python安装上，打算用VSCode来写python，但是就是报错，于是搜索了一下，在简书上找到了一篇文章，照着弄一弄终于成功了。简单记录下过程。

## 安装python插件

1. 打开VSCode，Ctrl+p
1. 输入 "ext install python"，搜索时间可能会比较长
1. 选择下载量最高的那个插件点击安装

到这VSCode就可以编辑python代码了，编辑完代码按F5即可运行。初次运行会让你选环境，选择python即可。

默认按F5后需要再按一次F5程序才会运行，如果要按F5马上运行需要将launch.json文件的 "stopOnEntry": true,改为 "stopOnEntry": false。

## 配置flake8

> 安装flake8之后写代码的时候编辑器就会提示哪里出错，代码格式不规范也会提示

1. 打开命令行
1. 输入 "pip install flake8"
1. 安装flake8成功后，打开VScode，文件->首选项->用户设置，在settings.json文件中输入"python.linting.flake8Enabled": true
