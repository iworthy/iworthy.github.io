### 前言
家用网络已经很少提供外网IP，即使是外网IP也封禁了许多端口，致使许多在家庭电脑上搭建的服务无法在外网访问，比如在家庭电脑上搭建minecraft服务器时就需要用到端口映射，提到端口映射我们会想到花生壳，不过花生壳变坏了，现在开始要钱，每个月还限制流量1g。1个g能干什么，卖萌么。这时候ngrok服务就可以帮助你解决问题。
### ngrok是什么
ngrok是一个反向代理，通过在公共的端点和本地运行的 Web 服务器之间建立一个安全的通道。ngrok 可捕获和分析所有通道上的流量，便于后期分析和重放
### ngrok相关连接
官网：https://ngrok.com/
由于ngrok官方服务器在国外，国内访问巨慢，推荐自行用国内vps搭建或使用国内提供的服务。
