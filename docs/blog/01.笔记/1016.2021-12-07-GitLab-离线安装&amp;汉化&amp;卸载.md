## 一、离线安装

### 1. 下载需求版本的rpm包，并传送到服务器

gitlab rpm下载地址：https://mirrors.tuna.tsinghua.edu.cn/gitlab-ce/yum/el6/

#### 2. 安装gitlab

```bash
$ rpm -ivh gitlab-ce-12.3.5-ce.0.el6.x86_64.rpm
```

#### 3. 修改配置文件

```bash
$ vim /etc/gitlab/gitlab.rb
```

配置http协议所使用的访问地址

```xml
external_url 'http://192.168.123.45'
```

####  4.初始化 GitLab

```bash
$ sudo gitlab-ctl reconfigure
```

#### 5. 启动gitlab

```bash
$ gitlab-ctl restart
```

IP访问，第一次访问，系统会要求重置新密码，**管理员的用户名为root**

## 二、汉化gitlab

### 1. 停止 GitLab 服务（汉化前）

```bash
$ gitlab-ctl stop
```

#### 2.下载中文补丁包

【重要】需要下载和gitlab同样版本的中文补丁包，不然可能会导致gitlab瘫痪，下载zh结尾（中文）
下载地址：https://gitlab.com/xhang/gitlab

#### 3. 解压

```bash
$ tar xf gitlab-v12.3.5-zh.tar.gz
```

#### 4. 复制并覆盖

```bash
$ \cp -rf ./gitlab-v12.3.5-zh/* /opt/gitlab/embedded/service/gitlab-rails/
```

复制完成后，需要重新加载配置，并启动Gitlab

```bash
$ gitlab-ctl reconfigure    
$ gitlab-ctl restart
```

登录完成，点击右上角的Settings进行Preferences设置，在语言项选择中文，

## 三、卸载

### 1、停止 GitLab 服务（卸载前）

```bash
$ gitlab-ctl stop
```

#### 2、卸载gitlab（注意这里写的是gitlab-ce）

```bash
$ rpm -e gitlab-ce
```

#### 3、查看gitlab进程

```bash
$ ps aux | grep gitlab
```

4、杀掉第一个进程（就是带有好多.............的进程）

```bash
$ kill -9 ID
```

杀掉后，在ps aux | grep gitlab确认一遍，还有没有gitlab的进程

5、删除所有包含gitlab文件

```bash
$ find / -name gitlab | xargs rm -rf
```
