macOS 的快捷键不难，真正容易让新用户困惑的是：Mac 用 `Command` 承担了 Windows 中大部分 `Ctrl` 的职责，而 `Option`、`Control` 和 `Fn` 又各自控制着不同层面的操作。本文以 **macOS Tahoe 26.5.2（构建版本 25F84）** 为环境，整理一份偏实用的快捷键速查表。

macOS Tahoe 26.5.2 于 2026 年 6 月 29 日发布，主要提供安全性修复，并未重新设计常用快捷键体系。因此，下面的大部分组合键也适用于相邻版本的 macOS；Tahoe 26 新增或容易混淆的部分会单独说明。

## 1. 先认识 Mac 键盘上的符号

Mac 的菜单栏经常只显示符号，不写按键全名。记住下面几个，就能看懂绝大多数菜单快捷键：

| 符号 | 按键 | 常见用途 |
| --- | --- | --- |
| `⌘` | Command | 复制、粘贴、保存、切换 App 等主要操作 |
| `⌥` | Option / Alt | 扩展功能、按词移动、改变操作方式 |
| `⌃` | Control | 调度中心、桌面切换、系统级组合键 |
| `⇧` | Shift | 反向选择或组合键的第二层功能 |
| `fn` / `🌐` | Fn / 地球仪键 | 功能键、听写、表情、窗口平铺等 |
| `⌫` | Delete | 向左删除；配合 `Fn` 可向右删除 |
| `⎋` | Esc | 取消、退出当前状态 |

如果使用的是 Windows 布局键盘，通常可以把 Windows 徽标键当作 `Command`，把 `Alt` 当作 `Option`。实际映射可以在“系统设置 → 键盘 → 键盘快捷键 → 修饰键”中调整。

## 2. 最值得先记住的快捷键

下面这组使用频率最高，先熟悉它们就能覆盖大部分日常操作。

| 快捷键 | 功能 |
| --- | --- |
| `⌘ C` / `⌘ V` | 拷贝 / 粘贴 |
| `⌘ X` | 剪切文本；在访达中不能直接剪切文件 |
| `⌘ Z` / `⇧ ⌘ Z` | 撤销 / 重做 |
| `⌘ A` | 全选 |
| `⌘ F` | 在当前 App 或文稿中查找 |
| `⌘ S` | 保存当前文稿 |
| `⌘ P` | 打印 |
| `⌘ W` | 关闭当前窗口或标签页，但不一定退出 App |
| `⌘ Q` | 退出当前 App |
| `⌘ ,` | 打开当前 App 的设置 |
| `⌘ Space` | 打开或隐藏聚焦搜索 |
| `⌘ Tab` | 在已打开的 App 之间切换 |
| <kbd>⌘</kbd> + <kbd>&#96;</kbd> | 在当前 App 的多个窗口之间切换 |
| `⌥ ⌘ Esc` | 打开“强制退出应用程序”窗口 |
| `⌃ ⌘ Q` | 立即锁定屏幕 |

`⌘ W` 和 `⌘ Q` 的区别很重要：前者通常只关窗口，后者才是退出 App。macOS 允许 App 在没有窗口时继续运行，因此点红色关闭按钮后，程序坞中的 App 图标下方仍可能有一个小圆点。

### 如何用键盘移动文件

访达没有 Windows 式的 `⌘ X` 剪切文件操作。正确做法是：

1. 选中文件，按 `⌘ C`。
2. 进入目标文件夹，按 `⌥ ⌘ V`。

这样会把文件移动到当前位置，而不是再复制一份。

## 4. 截图与录屏

macOS 自带的截图工具已经覆盖了全屏、区域、窗口和录屏需求。

| 快捷键 | 功能 |
| --- | --- |
| `⇧ ⌘ 3` | 截取整个屏幕 |
| `⇧ ⌘ 4` | 截取自选区域 |
| `⇧ ⌘ 4` 后按 `Space` | 截取指定窗口 |
| `⇧ ⌘ 5` | 打开截图与录屏控制栏 |
| 在上述组合键中加入 `⌃` | 将截图复制到剪贴板，不直接保存文件 |

使用区域截图时，拖动选区后暂时按住 `Space`，可以在不改变选区大小的情况下移动选区。默认截图通常保存在桌面，也可以在 `⇧ ⌘ 5` 的“选项”中更改保存位置和倒计时。

### Tahoe 26 的窗口平铺快捷键

macOS Tahoe 可以直接用键盘移动和调整活跃窗口：

| 快捷键 | 功能 |
| --- | --- |
| `Fn ⌃ F` | 让窗口填充桌面，但不进入全屏空间 |
| `Fn ⌃ C` | 将窗口居中 |
| `Fn ⌃ ←` / `Fn ⌃ →` | 将窗口放到桌面左半边 / 右半边 |
| `Fn ⌃ ↑` / `Fn ⌃ ↓` | 将窗口放到桌面上半边 / 下半边 |
| `Fn ⌃ R` | 恢复平铺前的窗口大小 |
| `Fn ⌃ ⇧ ←` / `Fn ⌃ ⇧ →` | 将当前窗口与另一个窗口左右排列 |

“填充桌面”和“全屏幕”不是一回事：前者仍保留菜单栏、程序坞和当前桌面环境；后者会进入独立的全屏空间。

## 6. 文本编辑与光标移动

这组快捷键在备忘录、邮件、Pages、浏览器输入框和大部分编辑器中都能使用，但个别 App 可能覆盖默认行为。

| 快捷键 | 功能 |
| --- | --- |
| `⌥ ←` / `⌥ →` | 按单词移动光标 |
| `⌘ ←` / `⌘ →` | 移到当前行开头 / 结尾 |
| `⌘ ↑` / `⌘ ↓` | 移到文稿开头 / 结尾 |
| 在上述移动组合中加入 `⇧` | 移动光标的同时选择文本 |
| `⌥ Delete` | 删除光标左侧的一个单词 |
| `Fn Delete` | 向右删除字符 |
| `⌘ B` / `⌘ I` / `⌘ U` | 粗体 / 斜体 / 下划线 |
| `⌘ K` | 为所选文本添加链接，具体取决于 App |
| `⌃ ⌘ Space` 或 `Fn E` | 打开字符检视器，输入表情与特殊符号 |

对于经常写文字或代码的人，`Option` 配合方向键和 `Delete` 很实用：它让光标和删除操作以“单词”为单位，比连续敲方向键快得多。

| 快捷键 | 功能 |
| --- | --- |
| `⌃ ⌘ Q` | 锁定屏幕 |
| `⌥ ⌘ Esc` | 强制退出无响应的 App |
| `⌃ 电源键` | 打开重新启动、睡眠和关机对话框，部分键盘适用 |

| `Fn N` | 显示或隐藏通知中心 |

在旧版本 macOS 中，`Fn ⇧ A` 对应的是“启动台”；从 Tahoe 26 开始，它对应新的“应用”界面。这是本文所列快捷键里最明显的版本差异之一。

涉及电源键的组合会因 Mac 机型、Touch ID 键盘和外接键盘而有所不同。强制重启或强制关机可能导致未保存内容丢失，不建议把它们当作常规快捷键使用。

## 9. 快捷键不生效时怎么排查

1. 查看 App 菜单栏中对应命令右侧显示的组合键。App 可以覆盖系统默认快捷键。
2. 检查输入法或键盘布局。部分按键位置会随布局变化，<kbd>⌘</kbd> + <kbd>&#96;</kbd> 尤其容易受影响。
3. 如果组合键包含 `F1` 至 `F12`，尝试同时按住 `Fn`；也可以在键盘设置中切换“将 F1、F2 等键用作标准功能键”。
4. 前往“系统设置 → 键盘 → 键盘快捷键”，检查快捷键是否被停用、修改或与输入法冲突。
5. 外接 Windows 键盘如果映射不顺手，可在“修饰键”设置中交换 `Command`、`Option` 和 `Control`。

## 10. 一份更容易记住的顺序

不需要一次背完所有组合键。可以按下面的顺序逐步形成肌肉记忆：

1. 先掌握 `⌘ C`、`⌘ V`、`⌘ Z`、`⌘ S`、`⌘ W` 和 `⌘ Q`。
2. 再加入 `⌘ Space`、`⌘ Tab`、<kbd>⌘</kbd> + <kbd>&#96;</kbd> 和 `Space` 快速查看。
3. 熟悉 `⇧ ⌘ 3/4/5`，解决所有截图和录屏需求。
4. 文件管理时记住 `⌘ C` 后接 `⌥ ⌘ V`。
5. 多窗口工作时再练习 `⌃ ↑`、`⌃ ←/→` 和 `Fn ⌃ ←/→`。

真正高效的不是记住最多快捷键，而是把每天重复十几次的鼠标操作替换掉。先挑三到五个最常用的组合坚持一周，通常比收藏一张庞大的快捷键表更有效。
