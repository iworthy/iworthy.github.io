## 安装方法

远程登录到 SSH，连接成功后输入以下命令进行安装：

```bash
bash <(curl -sL https://raw.githubusercontent.com/hijkpw/scripts/master/centos_install_ssr.sh)
```

## 配置信息

1. 查看ssr运行状态/配置：

   ```bash
   bash <(curl -sL https://raw.githubusercontent.com/hijkpw/scripts/master/centos_install_ssr.sh) info
   ```

2. SSR管理命令：

   - 启动：`systemctl start shadowsocksR`
   - 停止：`systemctl stop shadowsocksR`
   - 重启：`systemctl restart shadowsocksR`

3. 更改密码、端口、混淆参数的最简单方法：重新运行一次安装脚本。

4. 卸载SSR：

   ```bash
   bash <(curl -sL https://raw.githubusercontent.com/hijkpw/scripts/master/centos_install_ssr.sh) uninstall
   ```
