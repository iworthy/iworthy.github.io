GnuWin provides ports of tools with a GNU or similar open source license, to modern MS-Windows (Microsoft Windows 2000 / XP / 2003 / Vista / 2008 / 7)
gnuwin32主要是对习惯linux工具的人员，在windows上提供一套类似的命令。


<!--more-->

1. 下载GnuWin http://gnuwin32.sourceforge.net/
2. 运行下载的文件 解压到相应的文件夹
3. 运行download.bat ![Snipaste_2020-02-09_22-31-18.png][1]
4. 下载完后运行install.bat ![Snipaste_2020-02-09_22-34-28.png][2] ![Snipaste_2020-02-09_22-34-56.png][3]![Snipaste_2020-02-09_22-40-47.png][4]
5. 解压完成后配置环境变量 目录为 gnuwin32\bin
