## 1.安装JDK8（解压版本）

安装环境：Linux（Ubuntu）

JDK版本：jdk-8u191-linux-x64.tar.gz

```bash
yum remove -y openjdk

tar zxf jdk-8u191-linux-x64.tar.gz && mv jdk1.8.0_191/ /usr/local/jdk

vim /etc/profile

export JAVA_HOME=/usr/local/jdk
export JRE_HOME=$JAVA_HOME/jre
export CLASSPATH=.:$JAVA_HOME/lib:$JRE_HOME/lib
export PATH=$JAVA_HOME/bin:$PATH

source !$

java -version

ln -s /usr/local/jdk/bin/java /usr/local/bin/java
```

## 2.安装JDK8（RPM方式）

安装环境：Linux（Red Hat）

JDK版本：rpm -ivh jdk-8u191-linux-x64.rpm

```bash
rpm -ivh jdk-8u191-linux-x64.rpm

vim /etc/profile

export JAVA_HOME=/usr/java/jdk1.8.0_191-amd64
export CLASSPATH=$JAVA_HOME/lib
export JRE_HOME=$JAVA_HOME/jre
export PATH=$JAVA_HOME/bin:JRE_HOME/bin:$PATH

#注意：在PATH中$PATH要放在最后，如果放在前面，jdk会默认变成系统自带的jdk版本。

source /etc/profile

java -version
```

## 3.安装tomcat8.5

安装Tomcat之前要安装JDk

下载Tomcat8.5，将文件apache-tomcat-8.5.56.tar.gz移动到/usr/tomcat/下，并解压：

`tar -xzvf apache-tomcat-8.5.56.tar.gz`

修改端口，分别修改tomcat里面conf/server.xml

server.xml文件中有三个端口设置

```xml
<Server port="8005" shutdown="SHUTDOWN">
#关闭时使用
<Connector port="8080" protocol="HTTP/1.1" connectionTimeout="20000" redirectPort="8443" />
#一般应用使用
<Connector port="8009" protocol="AJP/1.3" redirectPort="8443" />
#AJP端口，即容器使用，如APACHE能通过AJP协议访问Tomcat的8009端口
```

启动tomcat，分别进入tomcat里面的bin目录

执行： `./startup.sh` -->启动tomcat

执行： `./shutdown.sh` -->关闭tomcat

浏览器中输入：localhost:8080即可访问tomcat

## 4.安装redis 单机

1.解压:`tar xzvf redis-4.0.8.tar.gz`

2.安装

```bash
cd redis-4.0.8
make
cd src
make install PREFIX=/usr/local/redis
```

3.移动配置文件到安装目录下

```bash
cd ../
mkdir /usr/local/redis/etc
mv redis.conf /usr/local/redis/etc
```

 4.配置redis为后台启动

`vi /usr/local/redis/etc/redis.conf //将daemonize no 改成daemonize yes`

5.设置redis密码为abc123

`vi /usr/local/redis/etc/redis.conf //将#requirepass 改成requirepass abc123`

6.开启redis

`redis-server /usr/local/redis/etc/redis.conf //启动redis`
