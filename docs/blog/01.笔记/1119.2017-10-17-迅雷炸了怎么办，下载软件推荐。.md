最近用迅雷极速版下文件视频，不仅由于版权原因不能加速，还有各种莫名奇妙的原因加速失败离线失败，有时候不用会员都比会员快，迅雷没有了下载留着它还有什么用，怒删，那么问题来了，接下来用什么下载呢。<!--more-->

在v2ex上（https://www.v2ex.com/t/397704?p=1） 看了相关的讨论后安装了FDM下载，不得不说满足基本下载还是不错的，而且官方的求推荐好可爱，如下图，于是首推一下它。

![](https://yun.worthy.cc/worthy/20171017223413.png)

下载地址：https://www.freedownloadmanager.org/
官方介绍：
Free Download Manager features
- Support for Windows and Mac OS X
- User-friendly interface with modern design
- Video downloading from popular websites
- HTTP/HTTPS/FTP/BitTorrent support
- Proxy support
- Fast, safe and efficient downloading

![](https://yun.worthy.cc/worthy/20171017223442.png)

推荐原因：安装浏览器插件后可以方便快捷的下载，支持http下载和bt下载，下载较快，界面美观。美中不足不支持ed2k连接，还需另外软件配合。

其他下载汇总：
1. IDM
2. uTorrent
3. qBittorrent
4. 百度网盘离线
5. aria2
