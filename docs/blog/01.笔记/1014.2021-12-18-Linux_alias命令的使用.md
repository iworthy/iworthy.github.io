Linux alias命令用来设置指令的别名，对一些较长的命令进行简化。使用alias时，必须使用单引号将原来的命令包含，防止特殊字符导致错误。

```bash
# 设置别名
$ alias 别名='原命令 -选项/参数'
# 查看已经设置的别名列表
$ alias -p
# 删除别名
$ unalias 别名
# 配置永久别名
打开`~/.bashrc`文件，输入要设置的alias命令,然后`source ~/.bashrc`
```
