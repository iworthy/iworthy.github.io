###ADB###
ADB工具下载：https://developer.android.google.cn/studio/releases/platform-tools

###黑阈###
黑阈（yù）不需要 root 就能待机（App Standby，Android 6.0 引入，部分设备不支持）或强行停止应用，防止应用持续运行。
激活命令：`.\adb -d shell sh /data/data/me.piebridge.brevent/brevent.sh`
使用说明书：https://jianyv.com/br/br.pdf
酷安链接：https://www.coolapk.com/apk/me.piebridge.brevent
