在网站建设中，选择合适的博客系统至关重要。Typecho 是一个简洁、快速且易于使用的博客系统，但是随着需求的增长，有时候需要更多功能和更好的用户体验。Vdoing 是一个基于 Vue.js 的静态博客系统，具有强大的自定义能力和良好的扩展性。本文将介绍如何将 Typecho 迁移到 Vdoing，并展示迁移过程中的关键步骤。

## 准备工作

在开始迁移之前，确保你已经完成以下准备工作：

1. **备份数据**：在迁移之前，务必对 Typecho 的数据库和文件进行备份，以防意外发生。

2. **了解 Vdoing**：熟悉 Vdoing 的安装和配置方法，确保你能够顺利进行后续操作。

## 迁移步骤

### 步骤一：导出 Typecho 数据

我使用了[Typecho-Plugin-Tp2MD](https://github.com/AlanDecode/Typecho-Plugin-Tp2MD)一个导出 Typecho 内容至 Markdown 文件的插件，支持丰富的 metadata，包括自定义字段、slug、分类、标签、日期等等，以 YAML front-matter 形式存储在文件顶部。经过测试还是完美兼容Vdoing的。

### 步骤二：安装 Vdoing

按照 Vdoing 的文档进行配置和初始化。使用Visual Studio Code或Webstorm内置的控制台即可。

```bash
# clone the project
git clone https://github.com/xugaoyi/vuepress-theme-vdoing.git

# enter the project directory
cd vuepress-theme-vdoing

# install dependency 注意：如安装不成功请关闭淘宝源。
npm install # or yarn install

# develop
npm run dev # or yarn dev
```

### 步骤三：导入数据到 Vdoing

```
.
├── .github   (可选，GitHub 相关文件)
│   ├── workflows
│   │   ├── baiduPush.yml (可选，百度定时自动推送)
│   │   └── ci.yml (可选，自动部署)
├── docs (必须，不要修改文件夹名称)
│   ├── .vuepress （同官方，查看：https://vuepress.vuejs.org/zh/guide/directory-structure.html#目录结构）
│   ├── @pages (可选，自动生成的文件夹，存放分类页、标签页、归档页)
│   ├── _posts (可选，专门存放碎片化博客文章的文件夹)
│   ├── <结构化目录>
│   └── index.md (首页)
├── vdoing (可选，本地的vdoing主题)
├── utils  (可选，vdoing主题使用的node工具)
│   ├── modules
│   ├── config.yml (可选，批量操作front matter配置)
│   ├── editFrontmatter.js (可选，批量操作front matter工具)
├── baiduPush.sh (可选，百度推送命令脚本)
├── deploy.sh (可选，部署命令脚本)
│
└── package.json
```

将Typecho导出的文件按类别放入docs──<结构化目录> 文件夹中即可。
