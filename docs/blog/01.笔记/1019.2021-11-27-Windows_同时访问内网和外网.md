# Windows 同时访问内网和外网

## 1.Windows 网络访问策略

打开 cmd， 键入 `route print` 命令，查看路由表

`cmd -> ipconfig /all`，查看默认网关
`cmd -> route print` ，查看 0.0.0.0 路由对应的网关就是当前网络的网关。

## 2.配置

当前网络环境：

```
内网：
地址: 192.168.123.234
掩码: 255.255.255.0
网关: 192.168.123.1
外网：
地址: 127.20.10.5
掩码: 255.255.255.0
网关: 127.20.10.1
```

注意：cmd 需要管理员权限，cmd -> 右键，管理员运行

删除路由：`route delete 0.0.0.0`      

为了可以访问内网，我们需要加上内网的路由：`route -p add 192.168.123.0 mask 255.255.255.0 192.168.123.1`

意思是当访问的站点ip是192.168.123开头，就走内网网关（192.168.123.1）

-p 是永久添加，电脑重启以后路由还在，不加的话，电脑关了以后路由就没了

访问外网：`route add 0.0.0.0 mask 0.0.0.0 127.20.10.1`

活着断开再重新连接外网网卡，会动态产生一个 0.0.0.0 的路由

删除永久路由   `route delete 192.168.123.1 mask 255.255.255.0 192.168.123.1`
